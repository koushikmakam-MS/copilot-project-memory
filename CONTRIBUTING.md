# Contributing to Copilot Project Memory

Thanks for your interest in contributing! 🎉

## How to Contribute

### Reporting Issues
- Open an [issue](https://github.com/koushikmakam-MS/copilot-project-memory/issues) with a clear description
- Include your OS (Windows/macOS/Linux) and Copilot CLI version

### Suggesting Features
- Open an issue with the `enhancement` label
- Describe the use case and expected behavior

### Pull Requests
1. Fork the repo
2. Create a feature branch: `git checkout -b feature/my-feature`
3. Make your changes
4. Test the installer on your OS
5. Submit a PR with a clear description

### What to Contribute
- **New auto-tracking patterns** — ideas for what else Copilot should observe
- **Editor support** — instruction file formats for new editors
- **Installer improvements** — better cross-platform support
- **Documentation** — usage examples, tutorials, translations

### Guidelines
- Keep the prompt (`copilot-instructions.md`) focused and actionable
- Don't add runtime dependencies — this is a prompt-based skill, not a code project
- Test installer changes on the target OS before submitting

## Code of Conduct

Be respectful, constructive, and inclusive. We follow the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
